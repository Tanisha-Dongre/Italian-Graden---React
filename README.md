# 🍝 Italian Garden Restaurant App

A responsive restaurant ordering application built using React.js. Users can browse Italian dishes, add items to the cart, remove items, and view the total order amount.

##  Features

- Responsive Design
- Food Menu Display
- Add to Cart
- Remove from Cart
- Dynamic Cart Total
- Modern UI

##  Technologies Used

- React.js
- JavaScript
- CSS3
- Vite

##  Project Structure

- Navbar Component
- Hero Section
- Menu Component
- Food Cards
- Cart Component
- Footer Component

npm install
npm run dev
